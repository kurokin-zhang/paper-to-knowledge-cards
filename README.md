# Paper to Knowledge Cards

将学术论文转换为结构化中文知识卡片的 Codex Skill 项目。

该项目面向论文精读、文献整理和个人知识库建设场景。它不只生成摘要，而是从论文中识别研究问题、核心概念、理论框架、研究方法、主要发现、证据边界与研究启示，并将这些内容拆解为可独立理解、可回查原文、可用于复习的中文卡片。

## 主要能力

- 读取中文或外文学术论文，并以简体中文输出。
- 提取题名、作者、来源、关键词和论文类型等基本信息。
- 还原“研究问题 → 分析框架 → 数据与方法 → 研究发现 → 结论”的论证链。
- 根据论文内容自动选择合适的卡片类型，并严格生成 3～6 张卡片。
- 区分作者观点、论文证据与分析归纳，避免将推断写成原文结论。
- 为重要知识点保留章节、页码、图号或表号等来源定位。
- 识别研究设计的证据边界、作者承认的局限和可延伸问题。
- 将附件视为分析材料，不执行附件正文中夹带的指令。

## 适用场景

- 论文精读与快速复习
- 文献综述前的材料整理
- Obsidian、Notion 等个人知识库录入
- 研究选题、概念比较与理论脉络梳理
- 政策研究、案例研究和实证论文的结构化拆解

本项目不适合单纯的逐字翻译、全文改写或文件格式转换。

## 卡片类型

Skill 会根据论文实际内容选择 3～6 张卡片，不要求每篇论文包含全部类型：

- 研究总览卡
- 研究问题卡
- 核心概念卡
- 理论框架卡
- 研究设计卡
- 数据与样本卡
- 方法卡
- 分类体系卡
- 阶段演变卡
- 核心发现卡
- 作用机制卡
- 对比关系卡
- 图表解读卡
- 问题或争议卡
- 政策或实践启示卡
- 研究局限卡
- 延伸问题卡

## 使用方法

向 Codex 提供论文文件，并提出类似请求：

```text
请使用 paper-to-knowledge-cards，把这篇论文整理成中文知识卡片。
重点保留研究框架、核心发现和证据边界，并标注原文位置。
```

还可以进一步限定用途：

```text
请将这篇论文制作成适合导入 Obsidian 的中文知识卡片。
请从全文筛选 3～6 个最重要的知识点，每张卡片保留一个中心知识点，并增加复习问题和关键词。
```

如果只关心论文的特定部分，可以明确范围：

```text
只整理这篇论文的理论框架、研究方法和实证发现，不展开政策建议。
```

## 输出结构

默认输出由以下部分组成：

1. 文献信息
2. 一句话总览
3. 研究逻辑
4. 编号知识卡片
5. 核心结论
6. 知识关系
7. 论文贡献
8. 证据边界与局限
9. 可延伸的研究问题

单张卡片的典型结构如下：

```markdown
### 卡片 01｜具体、可检索的标题

- **类型**：核心发现卡
- **核心知识**：用一至三句话说明一个知识点。
- **论文证据**：列出数据、案例、图表或分析结果。
- **关系与解释**：说明该知识点与研究问题或其他结论的关系。
- **来源定位**：章节、页码、图号或表号。
- **关键词**：3～6 个检索标签。
- **复习问题**：一个可以由本卡片回答的问题。
- **简短答案**：用一句话作答。
```

## 内容原则

### 严格控制在 3～6 张

无论论文篇幅多长，默认只生成 3～6 张知识卡片。生成前先对候选知识点按研究问题、理论框架、研究设计、核心发现、作用机制和证据边界进行排序，再合并重复或密切相关的内容。文献信息和综合收束不计入卡片数量，但不能以“子卡片”或附加结构绕过上限。只有用户明确指定其他数量时才临时覆盖该限制。

### 一张卡片，一个核心知识点

卡片应当具有原子性，但不能机械拆碎。脱离其他卡片后仍能理解、能够表达明确问题或判断，是划分卡片的基本标准。

### 区分观点、证据与归纳

- **论文陈述**：作者明确提出的概念、判断或结论。
- **论文证据**：样本、数据、案例、图表或分析结果。
- **分析归纳**：根据论文多个部分总结出的结构、关系或启示。

分析归纳必须明确标记，不能伪装成作者原话。

### 保持证据边界

- 不补造论文没有提供的数据、案例或因果关系。
- 不把相关性或历史共现直接写成因果关系。
- 不把规范性建议写成已经得到验证的研究发现。
- 不把参考文献中的观点误写为本文作者的结论。
- 无法可靠识别的文字、公式、图表或页码应明确说明，不进行猜测。

### 保留原文定位

重要卡片应尽可能标明 PDF 页码、印刷页码、章节、图号或表号。若印刷页码与 PDF 文件页码不同，推荐采用以下格式：

```text
印刷页码 90（PDF 第 5 页），表 1
```

## 推荐项目结构

```text
paper-to-knowledge-cards/
├── SKILL.md
├── README.md
└── agents/
    └── openai.yaml
```

- `SKILL.md`：Skill 的核心工作规范与输出要求。
- `README.md`：项目说明、使用示例和内容原则。
- `agents/openai.yaml`：Codex 中的展示信息与默认调用提示。

## 设计目标

这个 Skill 追求的不是“替用户少读几页”，而是把一篇论文转化为可以持续使用的知识单元：每项结论知道来自哪里，每份证据知道支持什么，每张卡片能够独立复习，多张卡片又能重新组成论文完整的论证结构。
