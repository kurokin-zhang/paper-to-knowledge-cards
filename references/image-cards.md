# Image 2 图片知识卡片规范

仅在用户要求将论文知识卡片制作成图片时读取本文件。

## 生成流程

1. 先按 `SKILL.md` 完成全文阅读、候选知识点筛选和 3～6 张文字卡片底稿。
2. 将每张文字卡片压缩为适合图片呈现的“画面文案”，不得直接把完整长卡片塞入图片。
3. 确定整组图片共享的视觉系统，再使用内置 `image_gen` 逐张生成，一次调用只生成一张卡片。
4. 生成后逐张查看原图，对照画面文案核验中文、数字、年份、逻辑关系和来源定位。
5. 发现乱码、漏字、错字、文字截断或虚构信息时，只针对该张图片重新生成，并重复所有文字约束。每张最多进行两次针对性修正；仍不可靠时，将文字底稿作为权威版本并明确指出该图片的文字问题。
6. 将最终图片保存到项目中的 `output/knowledge-cards/<paper-slug>/`，使用 `card-01.png` 至 `card-06.png` 的稳定文件名。不要覆盖同名旧文件，已有文件时添加版本号。

## 画面文案

每张图片只保留一个中心知识点，并控制文字密度：

- **编号**：`01 / 05` 形式。
- **标题**：不超过 18 个汉字，表达明确判断或问题。
- **核心结论**：1 句话，不超过 45 个汉字。
- **关键内容**：2～4 条短句，每条尽量不超过 28 个汉字。
- **证据**：最多 1 条关键数字、事实或方法说明；没有独立实证时写“规范分析”或“政策文本梳理”，不得制造数据。
- **来源**：只保留简短章节和页码，例如“第八节｜PDF 第 12 页”。完整来源定位继续保留在随图片提供的文字索引中。

删去复习问答、长段解释、完整文献题名和重复标签。不得为了装饰而缩小字号、堆叠密集文本或添加无关英文。

## 视觉系统

默认采用适合手机阅读的竖版学术信息卡：

- 画幅为竖版 4:5，留出充足安全边距；
- 风格简洁、克制、现代，兼具学术出版物与知识笔记质感；
- 使用米白或浅灰背景、深墨色正文和一种低饱和强调色；
- 标题、核心结论、证据和来源形成清晰的四级信息层次；
- 中文字体呈现清晰端正，避免书法体、装饰体和过细笔画；
- 同组卡片固定栅格、字号关系、配色、编号位置和页脚位置；
- 可使用少量线条、色块、箭头、时间轴或概念关系图辅助理解；
- 不添加人物肖像、照片背景、复杂纹理、品牌标识或水印，除非用户明确要求。

根据知识类型选择最小且准确的视觉表达：

- 阶段演变：时间轴；
- 概念对比：左右对照或二维矩阵；
- 理论框架：节点与箭头；
- 作用机制：因果链或流程图；
- 核心发现：重点数字与简洁关系图；
- 政策启示：分层路径或行动清单。

不得生成看似定量但没有论文数据依据的柱状图、折线图、比例图或地图。

## Image 2 提示词结构

每张图片使用以下结构组织提示词，并将所有需要出现的文字逐字写入引号：

```text
Use case: scientific-educational
Asset type: 中文论文知识卡片，手机竖屏阅读
Primary request: 将第 <N> 张知识卡片制作成清晰、克制、现代的学术信息图卡片
Scene/backdrop: 米白色纸张质感背景，轻微网格或细线辅助，留白充足
Subject: <知识类型对应的最小视觉结构>
Style/medium: 高质量编辑设计，学术出版物与知识笔记风格
Composition/framing: 竖版 4:5；固定卡片栅格；从上到下为编号、标题、核心结论、关键内容、证据、来源
Color palette: 深墨色正文，米白背景，统一的低饱和强调色
Text (verbatim):
"<编号>"
"<标题>"
"<核心结论>"
"<关键内容 1>"
"<关键内容 2>"
"<可选关键内容 3>"
"<证据>"
"<来源>"
Constraints: 所有中文逐字准确；文字清晰可读；同组卡片版式与配色一致；信息层级明确；不增删或改写给定文字
Avoid: 乱码、错别字、额外字符、文字截断、伪造数据、无依据图表、照片背景、人物、徽标、水印、二维码
```

用户提供配色、品牌或尺寸要求时，以用户要求为准，但仍需保持准确性、可读性和整组一致性。

## 交付格式

先展示 3～6 张最终图片，再提供一个紧凑的文字索引：

```markdown
1. 卡片标题 — `card-01.png` — 来源定位
2. 卡片标题 — `card-02.png` — 来源定位
```

文字索引用于检索和核对，不重复输出完整长卡片。若某张图片存在无法修正的文字问题，必须在对应索引中标明。
